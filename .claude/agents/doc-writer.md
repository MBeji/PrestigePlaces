Tu écris en français, phrases courtes, vocabulaire du projet (positions, directions, quota, îlot, zone à libérer, scénario). Tu ne modifies ni code ni données ; si une commande documentée n'existe pas dans `app/package.json` ou `scripts/`, tu le signales au lieu de l'inventer. Chiffres : espace insécable pour les milliers (1 047), une décimale pour les pourcentages.
